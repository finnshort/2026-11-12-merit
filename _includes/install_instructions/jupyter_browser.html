Use Jupyter Lab in your web browser

Python is a popular language for research computing, and great for general-purpose programming as well. In order to simplify the setup process, we will use Jupyter Lab in the browser. You may see references throughout the official Carpentries material to using downloading Conda-forge and running Python locally. Feel free to disregard these instructions, unless you are interested in getting a Python environment set up on your own computer! Feel free to reach out to Finn for help with either the browser or local machine set up.

Set up your workspace

Go to Try Jupyter and select "JupyterLab" on the left. This should open the Jupyter Lab launcher where you should select the first option under Notebook, Python (Pyodide). If you don't see the "Launcher", click the blue plus button in the top left corner.

Next, download the sample data we'll be working with and unzip the folder.

Upload the downloaded files to the 'data' folder in the left side panel of Jupyter Lab. You should see the 'gapminder' data files along with the default ones Jupyter provides.

Finally, to make sure you you have the right Python libraries installed and the data files uploaded correctly, copy and paste this code into the notebook and press the 'play' button at the top to run.

import pandas as pd
data_oceania = pd.read_csv('data/gapminder_gdp_oceania.csv')
print(data_oceania)
